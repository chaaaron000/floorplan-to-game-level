# 평면도 기호 읽기

네이버 부동산식 컬러 평면도(시그니엘 A1)와 분양 PDF 10개 계열에서 확인한 기호다. 다른 출처의 도면은 먼저 한두 군데를 확대해 같은 규칙인지 확인하고, 다르면 이 표에 덧붙인다.

평면의 모든 닫힌 영역과 굵은 띠는 아래 중 하나로 분류해 추적 파일에 적는다. 글자가 없는 영역도 이름을 붙여 따로 적는다. "추적 파일" 열의 표 이름과 종류는 [trace_template.py](trace_template.py)에 문법이 있다.

## 벽과 구조

| 보이는 것 | 뜻 | 추적 파일 |
|---|---|---|
| 굵은 띠(검정 또는 벽 색 채움) | 벽. 외벽이 더 굵을 수 있다 | `WALLS`, 띠의 네 가장자리. 칸막이 `P`, 코어 `C` |
| 두께가 제각각인 채움 덩어리 | 코어 벽, 샤프트·덕트·구조로 칠해진 면 | `WALLS` 종류 `M`. 채움 그대로 사각형 여러 개를 겹쳐 적는다 |
| 선으로만 그린 얇은 벽(채움 없음) | 얇은 칸막이 | `WALLS` 종류 `T` |
| 외곽을 따라 작은 블록이 반복되고 사이가 얇은 겹선 | 커튼월 멀리언과 유리 | `OUTLINE` + `GLAZING`(구간) 또는 `CURTAIN`(닫힌 중심선). 블록 위치로 멀리언 간격을 잰다 |
| 굵은 테두리의 큰 사각형 안에 X | 기둥 또는 큰 샤프트. 외벽에 붙어 있고 2m 넘으면 기둥일 가능성이 높다 | `COLUMNS`, 또는 `WALLS` 종류 `M`. 판단 근거를 머리말에 |
| 벽으로 둘러싸인 작은 사각형 안에 X | 설비 샤프트(PS/AD/EPS), 승강로 | 둘러싼 벽 + `SPACES` 바닥 종류 `core` |
| 대각선 빗금이나 여러 줄로 채운 작은 영역, 문 없음 | 출입 없는 수납·설비 공간 | 둘러싼 벽 + `SPACES`. 꽉 찬 덩어리로 보이면 `WALLS` 종류 `M` |

## 개구부

| 보이는 것 | 뜻 | 추적 파일 |
|---|---|---|
| 벽 띠가 끊기고 1/4 호 + 직선 | 여닫이문. 호의 중심이 힌지, 호가 그려진 쪽으로 열린다 | `DOORS` 종류 `single`, 힌지 쪽과 열리는 쪽 |
| 호가 양쪽에 둘 | 양개 여닫이 | `DOORS` 종류 `double` |
| 벽 띠 자리에 얇은 평행선 두 줄, 서로 어긋나게 겹침 | 미닫이문 | `DOORS` 종류 `slide`(한 짝), `slide_double`(가운데에서 양쪽). 유리는 `slide_glass`·`slide_double_glass`; 독립 샤워 문은 `RECT_DOORS` + `{'host': None}` |
| 수납 앞의 얇은 띠에 어긋난 겹선 | 붙박이장 미닫이 앞판 | `CLOSET_FRONTS` |
| 외벽 띠 자리에 얇은 겹선(어긋남 없음) | 창·유리 | `GLAZING` 구간 |
| 유리선이 세 줄인 베이 | 테라스로 나가는 미닫이 유리 | `GLAZING`의 미닫이 베이 |
| 벽 띠가 끊겼는데 문 기호가 없음 | 문짝 없는 통로 | `DOORS` 종류 `open` |
| 승강로 앞 벽의 끊김 | 승강기 문 | `DOORS` 종류 `elev` |

문을 적기 전에 그 자리의 벽 띠가 정말 끊겼는지 확대해서 본다. 끊기지 않은 벽에 문을 적으면 `plan_diff` 그림에서 그 구간이 빨강(평면에만 있는 벽)으로 남는다.

## 수납과 설비

| 보이는 것 | 뜻 | 추적 파일 |
|---|---|---|
| 벽에 붙은 얇은 선 사각형이 반복(칸 나눔) | 붙박이장·선반 | `CASEWORK`, 높이는 사진이나 관례 |
| 싱크(사각형 안 작은 원), 화구(원 두 개에 X), 배수 줄무늬 | 주방·다용도실 카운터 | `CASEWORK`(높이 0.9m 안팎) |
| 가는 겹선으로 두른 샤워 칸(안에 X가 있기도 하다) | 샤워 유리 | `GLASS_PARTITIONS`. 문 자리는 비워 적는다 |
| 변기·세면대·욕조 그림 | 위생기구 | 보통 모델링 범위 밖 |

| 벽 위를 지나는 빨간 점선 | One Za'abeel 바닥판 | 세대 경계(벡터 겹침). 현관문 위에도 그려진다 | 벽이 아니다. 그 아래의 벽 띠를 읽는다 |

## 무시할 것

- 방 이름 글자, 워터마크(예: "NAVER FINANCIAL", 분양 사이트 주소), 바닥 무늬(나뭇결, 체크무늬 타일), 가구 채색
- 바닥 색의 경계: 재질이 바뀌는 곳일 뿐 방 경계가 아니다. 벽 없이 나뉘는 방은 `VIRTUAL_SPLITS`로 나눈다.

## 자주 틀리는 곳

- 화장실 문을 막힌 벽에 두기: 문 기호(호·겹선)가 실제로 있는 벽을 확인한다.
- 미닫이를 여닫이로 읽기: 호가 없으면 여닫이가 아니다.
- X 상자를 그냥 넘기기: 샤프트·기둥이 빠지면 방이 실제보다 넓어지고 게임 안에 빈 구멍이 생긴다.
- 카운터·붙박이 외곽선을 벽으로 읽기: 채움 없는 가는 선이 벽에 붙어 있으면 `CASEWORK`다.
- 외곽 꼭짓점을 눈대중으로 찍기: 곡면은 원 맞춤으로, 사선은 띠 위 여러 점으로 직선을 맞춘 뒤 교점을 계산한다.
